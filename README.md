# 상벌점 관리 대시보드

상벌점 엑셀 파일을 올리면 학생 순위, 학년 순위, 반복 벌점 학생을 자동으로 보여주는 대시보드입니다.
같은 와이파이에 있는 다른 기기에서도 접속할 수 있습니다.

## 기능

- 엑셀(`.xlsx`) 업로드 → 자동 집계 (열 이름이 조금 달라도 인식: `학번/학생번호`, `이름/성명`, `점수/배점` 등)
- 학생 순위, 학년 순위, 반복 벌점 학생(3회 이상) 표시
- 화면 자동 갱신 (업로드하면 열려 있는 모든 화면에 바로 반영)
- 결과를 엑셀로 내보내기
- 후속지도 등급 기준 화면은 비밀번호로 보호, 지정된 선생님만 비밀번호 재설정
- 카카오톡 메시지 보내기 (선택, Kakao Developers 키 필요)

## 실행

[Node.js](https://nodejs.org)가 필요합니다.

```bash
npm install
cp .env.example .env      # Windows: copy .env.example .env  → 값 채우기
npm start                 # http://localhost:3030
```

실행하면 터미널에 같은 네트워크에서 접속할 주소(`http://192.168.x.x:3030`)도 나옵니다.

## 환경변수 (`.env`)

| 이름 | 설명 |
|---|---|
| `PORT` | 서버 포트 (기본 3030) |
| `TIER_PASSWORD` | 등급 기준 화면 비밀번호. 비우면 실행할 때마다 임시 비밀번호를 만들어 터미널에 보여줌 |
| `ADMIN_NAMES` | 비밀번호를 재설정할 수 있는 선생님 이름 (쉼표로 구분). 비우면 재설정 기능이 꺼짐 |
| `KAKAO_REST_API_KEY`, `KAKAO_ADMIN_KEY`, `KAKAO_CLIENT_SECRET` | 카카오톡 보내기용 (선택) |

`.env` 파일과 올린 엑셀(`data/`)은 GitHub에 올라가지 않습니다.

## 폴더 구조

| 경로 | 내용 |
|---|---|
| `server.cjs` | 서버 (엑셀 읽기, 집계, API, 카카오 연동) |
| `views/home.ejs` | 화면 |
| `public/` | 화면용 CSS·JS |

> 예전 `reward_manageer_system` 리포의 기록은 이 리포에 합쳐져 있습니다 (그 리포는 2026-11 삭제).
